# ADR-012: SHA-256 file hashing

Status: Accepted baseline; implementation LFI-023.

Hash authorized file bytes using streaming SHA-256 with cancellation. Record the
digest with a verified file revision; before/after identity/size/time changes discard
the result. Metadata timestamps alone are not content identity.

Use size plus SHA-256 for duplicate candidates; live access and content consent still
apply. Hashes are sensitive derived data and not authorization tokens. Distinct hard
links remain distinct paths; duplicate reporting must distinguish shared file identity
from potentially reclaimable duplicate bytes.
