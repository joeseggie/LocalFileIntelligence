# ADR-005: External-content FTS5

Status: Accepted baseline; schema Phase 1, search/extraction Phase 7.

Index file_contents.extracted_text using external-content FTS5, keyed by file_id,
with unicode61 and diacritic removal. Insert/update/delete triggers maintain consistency.
Metadata revisions, deletion, and access revocation invalidate cached content.

FTS is the first content retrieval strategy; no vector database or chunk tables in the
initial schema. Parameterize SQL and interpret queries as bounded literal terms rather
than exposing raw FTS syntax. Content grants are required for matching and excerpts.
Test real FTS matches after every mutation and purge, not just base-table counts.
